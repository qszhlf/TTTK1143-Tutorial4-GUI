TTTK1143 TUTORIAL 4 - JAVA SWING GUI

Four programs: DataSetApp, EdibleApp, MobileApp, PriceApp.
Existing supporting classes and interfaces are retained. Only the *App.java entry point in each program has been converted to an interactive Swing GUI.

HOW TO RUN (Windows, JDK installed):
1. Extract Tutorial4_GUI.zip.
2. Open one folder, for example DataSetApp.
3. Open a terminal inside the folder.
4. Run: javac *.java
5. Run: java DataSetApp

Repeat for the other folders, replacing DataSetApp with EdibleApp, MobileApp or PriceApp.

The PriceApp decision thresholds intentionally follow the original source:
Product uses salary > RM4000, and Car uses salary > RM8000.
These rules do NOT compare salary to the actual product price.

For the LMS submission shown in the screenshot, if it asks for a "link", upload each corresponding ZIP to cloud storage or an accessible repository and paste a shareable link. A local Windows file path will not work as a public link.
